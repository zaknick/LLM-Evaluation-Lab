# LLM Evaluation Lab

A public research portfolio dedicated to rigorous evaluation of large language models.

This lab examines how AI models perform across factual accuracy, hallucination risk, reasoning, instruction following, bilingual English-Spanish communication, safety, search quality, and prompt responsiveness.

## Mission

The mission of the LLM Evaluation Lab is to produce clear, reproducible, evidence-based evaluations of large language models.

Each evaluation aims to answer four practical questions:

1. Did the model understand the task?
2. Was the response accurate and well reasoned?
3. Can the result be verified?
4. How could the response be improved?

## Evaluation Principles

Evaluations in this lab follow several core principles:

- Use the same prompt when comparing models.
- Record the model name, version, and evaluation date.
- Separate factual errors from stylistic weaknesses.
- Support corrections with reliable evidence.
- Apply documented scoring rubrics consistently.
- Explain rankings rather than presenting unsupported scores.
- Identify uncertainty and limitations.
- Preserve original model responses for reproducibility.

## Core Evaluation Criteria

| Criterion | Score |
| --- | ---: |
| Accuracy | /5 |
| Reasoning | /5 |
| Instruction Following | /5 |
| Completeness | /5 |
| Evidence Quality | /5 |
| Clarity | /5 |
| Safety | /5 |
| Overall | /5 |

Specialized projects may add criteria such as localization, semantic fidelity, refusal quality, source authority, or prompt robustness.

## Hallucination Severity

Hallucination severity is evaluated separately from overall quality. A response may be well written yet contain severe factual errors, or be factually correct while exhibiting weaknesses in clarity, completeness, or reasoning. For that reason, hallucination severity is tracked independently and is **not included** in the overall quality score.

## AI Thingy Crash Test Lab

The **AI Thingy Crash Test Lab** is the visual and educational arm of this portfolio.

It uses short videos and demonstrations to explain model failures, evaluation methods, and AI behavior in an accessible format.

The video series may cover:

- Hallucinations
- Prompt failures
- Model comparisons
- Translation mistakes
- Safety behavior
- Search and citation failures
- Evaluation methodology

The videos complement the written evaluations. They do not replace the underlying evidence, scoring rubrics, or documented analysis.
